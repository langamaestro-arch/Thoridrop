# Thoridrop

Minecraft Java 26.3 / NeoForge project.

**Status: initial scaffold only, not a playable mod yet.** The current Java entry point initializes the mod; drops, waves, HUD, loot, and safe respawn remain to be implemented.

GitHub Actions attempts to compile with Java 25 and NeoForge MDK. A green build confirms compilation, not gameplay correctness.

See [DESIGN.md](DESIGN.md) for the intended mechanics.
